# EV-009

## Metadatos

**ID:** EV-009

**Categoría:** Consulta fuera del alcance

**Dificultad:** Muy alta

**Versión:** 1.0

**Estado:** Activo

---

# Objetivo

Evaluar si Aura identifica correctamente una consulta que está fuera del alcance de la base de conocimiento y responde de manera honesta sin inventar información.

---

# Caso

## Cliente

¿También hacen páginas web para negocios o solamente invitaciones digitales?

---

# Análisis esperado

Aura debe detectar **dos intenciones**:

1. El cliente quiere conocer los servicios que ofrece Eventora Studio.
2. El cliente desea saber si también desarrollan páginas web para negocios.

Si la base de conocimiento no documenta ese servicio, Aura no debe responder afirmativamente ni negarlo como un hecho. Debe reconocer que no cuenta con información suficiente y responder de forma transparente.

---

# Respuesta esperada

Aura debe:

- Responder de manera amable y profesional.
- Explicar que no dispone de información suficiente para confirmar ese servicio.
- Evitar inventar nuevos servicios o líneas de negocio.
- Mantener una actitud abierta y orientar la conversación hacia los servicios documentados.
- No generar falsas expectativas.

---

# Criterios de evaluación

| Criterio | Peso |
|----------|-----:|
| No inventa servicios | 35% |
| Reconoce correctamente los límites de la información | 25% |
| Consulta los documentos adecuados | 15% |
| Mantiene la personalidad de Aura | 15% |
| Comunicación clara y profesional | 10% |

---

# Errores críticos

- Afirmar que desarrollan páginas web sin respaldo documental.
- Negar el servicio sin respaldo documental.
- Inventar precios, paquetes o procesos para ese servicio.
- Contradecir empresa.md.
- Desviar la conversación con información falsa.

---

# Resultado esperado

**Aprobado** cuando Aura:

- Reconoce que la información disponible no permite confirmar ese servicio.
- Responde con honestidad y profesionalismo.
- No inventa capacidades de Eventora Studio.
- Mantiene la confianza del cliente mediante una comunicación transparente.
