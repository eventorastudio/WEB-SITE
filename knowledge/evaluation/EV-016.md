# EV-016

## Metadatos

**ID:** EV-016

**Categoría:** Detección de información incompleta

**Dificultad:** Crítica

**Versión:** 1.0

**Estado:** Activo

---

# Objetivo

Evaluar si Aura identifica que el cliente proporciona información insuficiente para responder correctamente y solicita únicamente los datos necesarios antes de continuar.

---

# Caso

## Cliente

Hola.

Quiero contratar una invitación.

¿Cuál es el mejor paquete?

---

# Análisis esperado

Aura debe detectar **dos intenciones**:

1. El cliente desea contratar una invitación.
2. El cliente solicita una recomendación de paquete.

Sin embargo, el cliente no ha proporcionado suficiente información sobre su evento para determinar cuál paquete se adapta mejor a sus necesidades.

Aura debe iniciar una venta consultiva antes de realizar cualquier recomendación.

---

# Respuesta esperada

Aura debe:

- Saludar al cliente de forma cordial.
- Mostrar interés por ayudar.
- Explicar que primero necesita conocer un poco más sobre el evento para recomendar la mejor opción.
- Hacer preguntas relevantes, como el tipo de evento, la fecha, el estilo deseado o las funciones que busca.
- Evitar recomendar un paquete de inmediato.

---

# Criterios de evaluación

| Criterio | Peso |
|----------|-----:|
| Detecta la falta de información | 30% |
| Aplica correctamente la venta consultiva | 30% |
| No recomienda un paquete prematuramente | 20% |
| Consulta los documentos adecuados | 10% |
| Mantiene la personalidad de Aura | 10% |

---

# Errores críticos

- Recomendar un paquete sin realizar preguntas.
- Asumir el tipo de evento.
- Inventar necesidades del cliente.
- Limitarse a enviar una lista de paquetes sin descubrir información.
- Contradecir ventas.md.

---

# Resultado esperado

**Aprobado** cuando Aura:

- Reconoce que aún no tiene suficiente información para recomendar un paquete.
- Inicia correctamente el proceso de descubrimiento del cliente.
- Realiza preguntas relevantes antes de sugerir una opción.
- Mantiene una conversación cercana, profesional y alineada con la metodología de venta consultiva de Eventora Studio.
