# EV-011

## Metadatos

**ID:** EV-011

**Categoría:** Manejo de información insuficiente

**Dificultad:** Muy alta

**Versión:** 1.0

**Estado:** Activo

---

# Objetivo

Evaluar si Aura identifica cuando no cuenta con suficiente información para responder una consulta y solicita únicamente los datos necesarios antes de ofrecer una recomendación.

---

# Caso

## Cliente

Hola.

Quiero una invitación.

¿Cuánto me va a costar?

---

# Análisis esperado

Aura debe detectar **dos intenciones**:

1. El cliente desea contratar una invitación.
2. El cliente solicita conocer el precio.

Sin embargo, no existe información suficiente para indicar un paquete o un costo específico, ya que primero debe comprender las necesidades del cliente mediante una venta consultiva.

---

# Respuesta esperada

Aura debe:

- Saludar al cliente de forma cordial.
- Mostrar disposición para ayudar.
- Explicar que el costo depende del paquete que mejor se adapte a sus necesidades.
- Evitar responder con un precio específico de inmediato.
- Hacer preguntas que permitan conocer mejor el evento antes de recomendar un paquete.

---

# Documentos que debe consultar

## Principal

- ventas.md

## Secundarios

- paquetes.md
- aura.md

---

# Criterios de evaluación

| Criterio | Peso |
|----------|-----:|
| Identifica la falta de información | 30% |
| Aplica correctamente la venta consultiva | 30% |
| Consulta los documentos adecuados | 15% |
| Mantiene la personalidad de Aura | 15% |
| Comunicación clara y profesional | 10% |

---

# Errores críticos

- Dar un precio específico sin realizar el descubrimiento del cliente.
- Recomendar un paquete inmediatamente.
- Inventar promociones o descuentos.
- Contradecir ventas.md o paquetes.md.
- Omitir las preguntas necesarias para conocer las necesidades del cliente.

---

# Resultado esperado

**Aprobado** cuando Aura:

- Reconoce que aún no tiene suficiente información para recomendar un paquete.
- Inicia el proceso de venta consultiva mediante preguntas relevantes.
- No inventa precios ni recomendaciones.
- Mantiene una conversación cercana, profesional y orientada a encontrar la mejor opción para el cliente.
