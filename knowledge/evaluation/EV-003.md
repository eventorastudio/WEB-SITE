# EV-003

## Metadatos

**ID:** EV-003

**Categoría:** Políticas de pago

**Dificultad:** Media

**Versión:** 1.0

**Estado:** Activo

---

# Objetivo

Evaluar si Aura responde correctamente una consulta sobre el proceso de pago respetando las políticas oficiales de Eventora Studio y sin agregar información inexistente.

---

# Caso

## Cliente

Hola.

Si contrato hoy, ¿cuánto tengo que pagar y cuándo pago el resto?

---

# Análisis esperado

Aura debe detectar **tres intenciones**:

1. Saludar al cliente.
2. Explicar el anticipo requerido para iniciar el proyecto.
3. Explicar cuándo debe liquidarse el pago restante.

La respuesta debe apegarse completamente a las políticas de pago de Eventora Studio.

---

# Respuesta esperada

Aura debe:

- Saludar al cliente.
- Explicar que para iniciar el proyecto se requiere un anticipo del **30%** del paquete seleccionado.
- Explicar que el **70% restante** se liquida una vez aprobado el diseño y antes de la entrega final.
- Mantener una comunicación clara y profesional.
- No inventar promociones, descuentos o formas de pago diferentes.

---

# Criterios de evaluación

| Criterio | Peso |
|----------|-----:|
| Explica correctamente el anticipo | 30% |
| Explica correctamente el pago final | 25% |
| Consulta los documentos adecuados | 20% |
| Mantiene la personalidad de Aura | 15% |
| No inventa información | 10% |

---

# Errores críticos

- Cambiar el porcentaje del anticipo.
- Cambiar el momento en que se realiza el pago final.
- Inventar promociones o descuentos.
- Inventar métodos de pago.
- Contradecir pagos.md o proceso.md.

---

# Resultado esperado

**Aprobado** cuando Aura:

- Explica correctamente el esquema de pagos.
- Mantiene una respuesta clara y profesional.
- Respeta completamente las políticas de Eventora Studio.
- No agrega información que no exista en la base de conocimiento.
