# EV-002

## Metadatos

**ID:** EV-002

**Categoría:** Recomendación de paquetes

**Dificultad:** Alta

**Versión:** 1.0

**Estado:** Activo

---

# Objetivo

Evaluar si Aura evita recomendar un paquete sin contar con suficiente información y mantiene correctamente el enfoque de venta consultiva.

---

# Caso

## Cliente

Hola.

Quiero contratar una invitación.

¿Cuál paquete me recomiendas?

---

# Análisis esperado

Aura debe detectar **tres intenciones**:

1. Saludar al cliente.
2. Identificar que el cliente desea contratar.
3. Solicitar una recomendación de paquete.

Aunque el cliente desea una recomendación, todavía no existe suficiente información para determinar cuál es la mejor opción.

---

# Respuesta esperada

Aura debe:

- Saludar al cliente.
- Agradecer el interés en Eventora Studio.
- Explicar que cuenta con diferentes paquetes diseñados para distintas necesidades.
- Evitar recomendar un paquete inmediatamente.
- Hacer preguntas para conocer el evento, el estilo deseado o las necesidades del cliente antes de emitir una recomendación.

---

# Documentos que debe consultar

## Principal

- ventas.md

## Secundarios

- paquetes.md
- aura.md

---

# Criterios de evaluación

| Criterio | Peso |
|----------|-----:|
| Detecta correctamente la intención | 25% |
| No recomienda un paquete sin contexto | 25% |
| Consulta los documentos adecuados | 20% |
| Mantiene la personalidad de Aura | 15% |
| Continúa correctamente la venta consultiva | 15% |

---

# Errores críticos

- Recomendar Esencial, Premium o Prestige sin conocer las necesidades del cliente.
- Inventar características de los paquetes.
- Presionar al cliente para comprar.
- Responder únicamente con una lista de paquetes.
- Omitir preguntas de descubrimiento.

---

# Resultado esperado

**Aprobado** cuando Aura:

- Mantiene el enfoque consultivo.
- Evita asumir información.
- Descubre las necesidades del cliente antes de recomendar una solución.
- Mantiene una conversación cercana, profesional y natural.
