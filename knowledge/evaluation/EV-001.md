# EV-001

## Metadatos

**ID:** EV-001

**Categoría:** Múltiples intenciones

**Dificultad:** Alta

**Versión:** 1.0

**Estado:** Activo

---

# Objetivo

Evaluar si Aura puede identificar múltiples intenciones en un solo mensaje, consultar los documentos adecuados y construir una respuesta organizada sin omitir información.

---

# Caso

## Cliente

Hola.

Me caso en noviembre.

No sé cuál paquete elegir.

¿Aceptan PayPal?

¿Y cuánto tendría que pagar para empezar?

---

# Análisis esperado

Aura debe detectar que el mensaje contiene **cuatro intenciones**:

1. Saludo.
2. El cliente organizará una boda.
3. Solicita una recomendación de paquete.
4. Pregunta si acepta PayPal.
5. Pregunta cuánto debe pagar para iniciar.

Aunque el cliente ya menciona que es una boda, todavía no existe suficiente contexto para recomendar un paquete específico.

---

# Respuesta esperada

Aura debe:

- Saludar de forma cálida.
- Reconocer que se trata de una boda.
- Explicar que cuenta con tres paquetes disponibles.
- Evitar recomendar un paquete todavía.
- Confirmar que acepta PayPal como método de pago.
- Explicar que el proyecto inicia con un anticipo del 30% y que el 70% restante se liquida después de la aprobación del diseño y antes de la entrega.
- Finalizar realizando una pregunta que permita conocer las necesidades del cliente para recomendar el paquete más adecuado.

---

# Documentos que debe consultar

## Principal

## Secundarios

- paquetes.md

# Criterios de evaluación

| Criterio | Peso |
|----------|-----:|
| Detecta todas las intenciones | 30% |
| Consulta los documentos correctos | 20% |
| Mantiene la personalidad de Aura | 15% |
| No inventa información | 15% |
| Responde todas las preguntas | 10% |
| Conduce correctamente el siguiente paso | 10% |

---

# Errores críticos

- Recomendar un paquete sin conocer las necesidades del cliente.
- Omitir alguna de las preguntas.
- Inventar precios.
- Inventar funciones de los paquetes.
- Indicar un porcentaje de anticipo diferente al establecido.
- Omitir el saludo inicial.
- Contradecir cualquier documento de la base de conocimiento.

---

# Resultado esperado

**Aprobado** cuando Aura:

- Detecta todas las intenciones.
- Responde cada una correctamente.
- Mantiene una conversación natural.
- Respeta las políticas.
- Continúa con la venta consultiva solicitando información adicional para recomendar el paquete adecuado.
