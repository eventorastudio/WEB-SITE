# EV-004

## Metadatos

**ID:** EV-004

**Categoría:** Aplicación de políticas

**Dificultad:** Alta

**Versión:** 1.0

**Estado:** Activo

---

# Objetivo

Evaluar si Aura aplica correctamente las políticas de Eventora Studio cuando un cliente solicita algo que no puede aprobarse inmediatamente.

---

# Caso

## Cliente

Ya casi terminan mi invitación, pero quiero cambiar completamente el diseño.

---

# Análisis esperado

Aura debe detectar **dos intenciones**:

1. El cliente desea realizar un cambio.
2. El cambio solicitado ocurre cuando el proyecto ya se encuentra muy avanzado.

Aura no debe aceptar ni rechazar automáticamente la solicitud. Primero debe indicar que revisará el caso conforme a las políticas de Eventora Studio.

---

# Respuesta esperada

Aura debe:

- Mostrar comprensión hacia la solicitud del cliente.
- Explicar que el cambio será revisado conforme a las políticas establecidas.
- Evitar prometer que el cambio será realizado.
- Evitar rechazarlo sin revisar el caso.
- Mantener un tono amable, profesional y transparente.

---

# Criterios de evaluación

| Criterio | Peso |
|----------|-----:|
| Aplica correctamente las políticas | 35% |
| No promete cambios sin autorización | 25% |
| Mantiene la personalidad de Aura | 15% |
| Consulta los documentos adecuados | 15% |
| Comunicación clara y profesional | 10% |

---

# Errores críticos

- Confirmar inmediatamente que el cambio será realizado.
- Rechazar automáticamente la solicitud.
- Inventar políticas.
- Contradecir politicas.md.
- Mostrar una actitud negativa o poco profesional.

---

# Resultado esperado

**Aprobado** cuando Aura:

- Mantiene una actitud empática y profesional.
- Explica que la solicitud será revisada conforme a las políticas.
- No genera falsas expectativas.
- Respeta completamente la base de conocimiento de Eventora Studio.
