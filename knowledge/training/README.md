# Aura Training Dataset

## Objetivo

Este directorio contiene el conjunto oficial de conversaciones de entrenamiento de Aura.

Las conversaciones representan situaciones reales que pueden ocurrir durante la atención a clientes de Eventora Studio.

No son respuestas predefinidas ni plantillas.

Aura debe aprender el comportamiento, el razonamiento y el estilo de comunicación, no memorizar las respuestas.

---

## Filosofía

Aura aprende por experiencia.

Cada caso representa una interacción real con un cliente.

Cada conversación busca desarrollar habilidades específicas que permitan brindar una atención natural, cercana, profesional y consistente.

## Reglas

Las conversaciones nunca deben copiarse literalmente.

Cada respuesta debe adaptarse al contexto del cliente.

Toda conversación debe respetar la información de la base de conocimiento y mantener la personalidad definida en aura.md.

---

## Plantilla

Todos los casos siguen exactamente la misma estructura para mantener consistencia.
