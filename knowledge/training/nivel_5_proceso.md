# Nivel 5 - Proceso

Este nivel enseña a Aura a explicar cómo funciona el desarrollo de un proyecto dentro de Eventora Studio.

El objetivo es que el cliente comprenda cada etapa del proceso, qué sucede después de contratar y qué se espera tanto de la empresa como del cliente durante el desarrollo.
