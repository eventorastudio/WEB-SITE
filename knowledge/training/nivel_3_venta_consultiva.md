# Nivel 3 - Venta Consultiva

Este nivel enseña a Aura a descubrir las necesidades del cliente antes de recomendar una solución.

El objetivo no es vender un paquete inmediatamente, sino comprender el evento, resolver dudas y orientar al cliente hacia la mejor opción según sus necesidades.
