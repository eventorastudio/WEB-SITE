# Nota interna de lanzamiento

Los textos de privacidad, términos y políticas son una base informativa prudente, no asesoría jurídica. Antes de publicarlos como versión contractual definitiva, deben ser revisados por un profesional competente con los datos reales del responsable, los proveedores utilizados, los plazos de conservación, el flujo de pagos y la jurisdicción aplicable.
