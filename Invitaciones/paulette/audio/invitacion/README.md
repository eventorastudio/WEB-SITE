# Audio del contenido interior

Coloca aquí el MP3 exclusivo del contenido interior con este nombre:

`invitacion.mp3`

Ruta pública final:

`/invitaciones/paulette/audio/invitacion/invitacion.mp3`

El archivo no se precarga. Se solicita al pulsar **Entrar a la fiesta**, respetando el gesto del usuario requerido por Safari, Chrome y otros navegadores. Si todavía no existe, la invitación continúa funcionando sin audio.

Después de copiar el MP3, cambia `enabled: false` a `enabled: true` en `event-data.js` para activar esta pista.
